# E-Commerce Delivery Performance Dashboard

An interactive Tableau dashboard analyzing 96,470
e-commerce orders to evaluate delivery performance,
track business KPIs, and identify regional delivery trends.

## Key Features
- Total Orders: 96,470
- On-Time Delivery Rate: 91.89%
- Late Orders: 7,820
- Average Delivery Duration: 12.56 Days
- Monthly Order Trend Analysis
- Top 10 States by Late Orders

## Tools & Technologies
- Tableau Public
- Calculated Fields
- Data Visualization
- Dashboard Design
