# E-Commerce-Delivery-Performance-Dashboard-Tableau-
An interactive Tableau dashboard designed to analyze and visualize e-commerce delivery performance across 96,470 orders.

The project focuses on evaluating delivery efficiency, identifying order delays, and understanding regional delivery patterns through interactive data visualization.

**Key Features:**
- Developed KPI visualizations to monitor total orders, on-time delivery rate (91.89%), late orders (7,820), and average delivery duration (12.56 days).
- Analyzed monthly order trends to identify changes in order volumes over time.
- Identified the top 10 states with the highest number of late deliveries.
- Implemented calculated fields and year-based filters for dynamic data exploration.
- Designed interactive visual indicators to highlight delivery performance and operational bottlenecks.

**Technologies Used:** Tableau Public, Calculated Fields, Data Visualization, Dashboard Design.

**Objective:** To transform raw e-commerce delivery data into meaningful business insights that support operational analysis and data-driven decision-making.
